# Terminal Intermodal - Solução ASP.NET Core (.NET 10) com OR-Tools

## Pré-requisitos
- .NET 10 SDK instalado

## Como Executar
1. Abra a linha de comandos na pasta descompactada.
2. Execute:
```bash
dotnet run
```
3. Abra no browser: **http://localhost:5000** (ou a porta indicada na consola).

A API disponibiliza os endpoints em `/api/terminal` e o simulador interativo em `/`.
